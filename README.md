# Multi-Document RAG Assistant with Citations

A Streamlit app for asking questions across multiple PDFs, returning document/page citations, comparing two documents, and running a basic evidence-support check.

## Architecture

1. **Upload PDFs** through Streamlit.
2. **Load pages and metadata** with `PyPDFLoader`; keep filename and one-based page number.
3. **Recursive chunking** with `RecursiveCharacterTextSplitter` (`CHUNK_SIZE=1000`, `CHUNK_OVERLAP=150` by default).
4. **Free local embeddings** with Hugging Face `sentence-transformers/all-MiniLM-L6-v2`.
5. **Persistent vector storage** in Chroma (`./chroma_db`).
6. **Multi-query retrieval**: Gemini rewrites a question into alternative queries; Chroma retrieves relevant chunks and the retriever merges results.
7. **Grounded answer generation** with Gemini. The prompt requires inline `[filename, p. X]` citations and an insufficient-evidence response.
8. **Comparison and basic evaluation**: compare evidence from two documents; assess whether retrieved context supports a question.

## Project files

- `app.py` — Streamlit user interface
- `rag_pipeline.py` — loading, splitting, embeddings, Chroma, multi-query retrieval, answers, comparison, evidence checks
- `requirements.txt` — Python packages
- `.env` — local API key and configuration (keep private)
- `.gitignore` — excludes secrets, environment, and database

## 1. Requirements

- Python 3.11 or 3.12 recommended.
- Internet connection for installing packages, downloading the embedding model on first run, and Gemini API requests.
- A Gemini API key. The Hugging Face embedding model runs locally and does not require an embedding API key.

## 2. Create and activate a virtual environment (Windows PowerShell)

Open PowerShell in this project folder:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, use this for the current terminal only:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

Alternative without activation:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

A virtual environment is created on your computer; it is intentionally not bundled in the ZIP because it is OS- and Python-version-specific.

## 3. Configure Gemini

1. Open Google AI Studio and create a Gemini API key for a model available to your account.
2. Open `.env`.
3. Replace `paste_your_gemini_api_key_here` with the key.
4. Save the file. Do not share the key or commit `.env` to GitHub.

The Gemini free tier, quotas, supported models, and regional availability can change. Check your Google AI Studio account if a model returns quota or availability errors. The app needs Gemini for multi-query rewriting and answer generation.

## 4. Run the app

```powershell
streamlit run app.py
```

Upload PDFs in the sidebar, click **Index uploaded PDFs**, and then ask a question in the **Ask questions** tab.

## 5. Important notes

- The first embedding-model run downloads model files and may take a few minutes.
- Scanned/image-only PDFs may produce little or no text. OCR them first (for example, with an OCR tool) before uploading.
- Chroma data persists under `chroma_db/`. Keep this folder to retain the index. Delete it only if you intentionally want to rebuild the index.
- Re-uploading the same filename updates matching chunk IDs, but changing a PDF's page/chunk layout can leave old chunk IDs behind. For a clean rebuild, stop Streamlit and remove `chroma_db/`, then restart and re-index all PDFs.
- Citation page numbers are one-based PDF page numbers. They may differ from printed page labels inside a report.
- The UI shows retrieved excerpts to make answers auditable. Inline citations are generated by the LLM and should be checked against those excerpts.
- The evaluation tab is a basic LLM-assisted evidence check, not a validated RAG benchmark. For rigorous evaluation, build a test set with expected source pages/answers and measure retrieval Recall@k/MRR plus answer faithfulness.
- Do not upload confidential documents unless you are permitted to send their relevant text to the configured Gemini API.

## Troubleshooting

**`GEMINI_API_KEY is missing`**: check `.env` is in the same folder as `app.py`, and the key is set.

**Model not found / quota / 429**: confirm the current model name and quota in Google AI Studio; update `GEMINI_MODEL` in `.env` if needed.

**Import error after installation**: confirm the `.venv` is active and install packages with `python -m pip install -r requirements.txt`.

**No useful text extracted**: PDF may be scanned. OCR it first.

**Slow first launch**: the Hugging Face model downloads on first use and runs locally on CPU by default.
